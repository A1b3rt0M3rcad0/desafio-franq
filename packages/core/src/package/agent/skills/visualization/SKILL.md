description: Seleciona a representação visual adequada para listas, comparações e tendências dos resultados.
-----------------------------------------------------

# Objetivo

Escolher uma visualização que represente os dados encontrados sem distorcer sua interpretação.

# Seleção

- Use tabela quando o usuário precisar ler valores individuais, rankings ou listas detalhadas.
- Use barras para comparar categorias, canais, estados, produtos ou outros grupos discretos.
- Use linha para tendências e evolução temporal em uma sequência ordenada de datas ou períodos.
- Não gere gráfico quando uma resposta textual simples comunicar melhor o resultado.
- Respeite explicitamente o tipo de visualização solicitado pelo usuário quando os dados forem
  compatíveis com ele.

# Validação

Antes de escolher a visualização, confirme que os campos usados nos eixos ou na tabela existem
no resultado real. Não invente séries, categorias ou pontos ausentes.
