# Objetivo

Converter resultados de uma ou mais operações em uma conclusão de negócio precisa, distinguindo
o que é evidência observada do que seria inferência.

# Procedimento

1. Verifique se o resultado obtido realmente responde à pergunta ou apenas a uma parte dela.
2. Relacione múltiplos resultados somente quando as dimensões, filtros e granularidades forem
   compatíveis.
3. Preserve unidades, períodos, critérios de filtro e definições relevantes.
4. Procure inconsistências evidentes antes de concluir.
5. Se faltar evidência para uma conclusão importante, solicite nova operação em vez de preencher
   a lacuna com uma suposição.
6. Quando houver incerteza que não possa ser resolvida com os dados disponíveis, informe-a na
   resposta final.

# Resposta

Priorize a conclusão que ajuda o usuário a tomar uma decisão. Apresente números e comparações
relevantes de forma direta e mantenha rastreáveis os critérios que alteram a interpretação.
